## 1. 软件概述

### 1.1 软件用途

本软件用于**核安全壳隔离阀泄漏率试验**的全流程数据管理，涵盖：

- 基础台账维护（项目、机组、试验对象路径树、测量装置）
- 试验路径（配方）配置与版本管理
- 现场数据包导入（单文件/批量）
- 实时采集 PLC 数据并绘制趋势曲线
- 试验记录管理、判定与曲线回放
- 多维度历史数据统计分析
- 试验报告导出（Excel / PDF）
- 数据库主从高可用、自动备份

### 1.2 界面布局

## 3. 首页概览

首页是软件启动后的默认页面，提供全局数据一览。

展示最近一次导入的详细信息：

### 3.4 台账概况（底部左侧）

9 个指标卡片分 3 行显示：

| 行 | 指标 |

| 第 2 行 | 贯穿件数、阀门数、部件数 |
| 第 3 行 | 试验记录数、合格数、不合格数 |

### 3.5 系统维护（底部右侧）

显示系统运行状态：

| 项目 | 说明 |
|------|------|

## 4. 基础台账（试验对象）

**操作入口**：左侧导航 → "试验对象"

基础台账页面包含 **4 个 Tab**：

| Tab | 名称 | 功能 |
|-----|------|------|
| 1 | 项目/机组 | 管理项目和机组 |
| 2 | 试验对象管理 | 管理试验对象路径树 |
| 3 | 测量装置 | 管理测量装置台账 |
| 4 | 报告导出 | 导出试验报告 |

### 4.1 Tab 1：项目/机组管理

**左侧：项目列表** | **右侧：机组列表**（按选中项目过滤）

#### 项目管理

| 操作 | 步骤 |
|------|------|
| **新增** | 点击"新增" → 填写项目名称、启用状态、备注 → 确定（编码自动生成，格式 `P{yyMM}{序号}`） |
| **编辑** | 选中项目 → 点击"编辑" → 修改名称/状态/备注 → 确定 |
| **删除** | 选中项目 → 点击"删除" → 确认（已关联机组的项目可能无法删除） |

#### 机组管理

| 操作 | 步骤 |
|------|------|
| **新增** | 先选中左侧项目 → 点击"新增" → 填写机组名称、启用状态、备注 → 确定 |
| **编辑** | 选中机组 → 点击"编辑" → 修改 → 确定 |
| **删除** | 选中机组 → 点击"删除" → 确认 |

#### 批量导入
点击 **"批量导入数据"** → 选择包含项目/机组数据的文件夹 → 系统自动解析导入，进度条显示进度。

### 4.2 Tab 2：试验对象管理（路径树）

试验对象采用 **四级层级树结构**：

```
系统 (System)
  └── 贯穿件 (Penetration)
        ├── 阀门 (Valve) ← 可试验的叶子节点
        └── 其他部件 (OtherComponent) ← 可试验的叶子节点
```

#### 页面布局
- **顶部**：项目/机组下拉框（范围过滤）+ 搜索框
- **左侧**：试验对象树（可展开/折叠）
- **右侧上**：选中节点的详细信息
- **右侧中**：该对象的试验统计（累计试验、合格/不合格次数、最近结果等）
- **右侧下**：关联试验路径信息（配方名称、泄漏率限值、预充压 P2）

#### 新建节点

底部 4 个快速新建按钮：

| 按钮 | 创建的节点类型 | 前置条件 |
|------|--------------|----------|
| 🏗 新建系统 | 系统节点（顶级） | 无 |
| 🔩 新建贯穿件 | 贯穿件节点 | 需先选中一个系统节点 |
| 🔧 新建阀门 | 阀门节点（叶子） | 需先选中一个贯穿件节点 |
| ⚙ 新建其他部件 | 其他部件节点（叶子） | 需先选中一个贯穿件节点 |

#### 节点编辑对话框

点击"修改节点"或新建后弹出对话框，可编辑：

| 字段 | 说明 |
|------|------|
| 节点编码 | 唯一标识 |
| 节点名称 | 中文名称 |
| 节点类型 | 系统/贯穿件/阀门/其他部件（部分节点不可改） |
| 泄漏率限值 | 判定合格/不合格的依据（叶子节点可设） |
| 试验压力 | 试验时的压力参数 |
| 默认关联试验路径 | 为该节点指定默认配方（仅叶子节点） |
| 备注 | 补充说明 |

#### 节点操作

| 操作 | 说明 |
|------|------|
| ✏ 修改节点 | 编辑节点属性 |
| 📥 导入数据 | 为该节点导入试验数据 |
| 📤 导出数据 | 导出该节点的历史试验数据 |
| 🗑 删除节点 | 删除节点（有历史数据的节点可能无法删除） |

#### 搜索定位
输入关键字 → 点击"搜索" → 树自动展开并高亮匹配的节点。

### 4.3 Tab 3：测量装置台账

#### 筛选条件
- **主通信方式**：USB / RJ45 / RS232 / RS485
- **启用状态**：启用 / 停用
- **关键字搜索**：按装置编号/名称搜索

#### 装置列表

| 列 | 说明 |
|---|------|
| 装置编号 | 唯一标识（新增时自动生成，格式 `DEV-{yyyyMMddHHmm}`） |
| 装置名称 | 装置中文名 |
| IP | 装置 IP 地址 |
| 序列号 | 装置出厂序列号 |
| 主通信方式 | USB/RJ45/RS232/RS485 |
| 启用状态 | 启用/停用 |
| 最近连接状态 | 在线/离线/未知 |
| 最近同步时间 | 最后数据同步时间 |
| 最近导入时间 | 最后数据导入时间 |

#### 新增装置
1. 点击 **"新增装置"**
2. 填写：装置名称、IP、序列号、主通信方式、启用状态、备注
3. 确定保存

> **提示**：实时监视中选择测量装置时，只有"启用"状态的装置可供选择。"未指定"是系统保留装置，不会出现在选择列表中。

### 4.4 Tab 4：报告导出

#### 导出配置

| 配置项 | 选项 |
|--------|------|
| **导出范围** | 全部试验记录 / 本月试验记录 / 本月合格记录 / 本月不合格记录 |
| **导出格式** | Excel / PDF |
| **文件名** | 自定义（留空则自动生成） |
| **导出目录** | 可浏览选择 |

#### 快速导出
- **"导出 Excel"** 按钮：一键导出全部记录到 Excel 工作簿
- **"导出 PDF"** 按钮：一键导出（每条记录一个页面）

#### Excel 报告内容
试验记录汇总表 + 统计汇总

#### PDF 报告内容
单条试验记录的详细信息（项目、机组、对象、时间、结果、曲线等）

## 5. 试验路径（配方管理）

**操作入口**：左侧导航 → "试验路径"

管理试验路径（配方），定义试验参数（泄漏率限值、压力、阀门规格等）。

### 5.1 工具栏

| 按钮 | 功能 |
|------|------|
| 搜索框 + "搜索" | 按关键字搜索配方（支持回车） |
| "只显示启用试验路径" | 复选框，过滤已禁用的配方 |
| "导入CSV" | 从 CSV 文件批量导入配方（自动检测 GBK/UTF-8 编码） |
| "导出CSV" | 导出配方列表为 CSV（GBK 编码） |
| ＋新增 | 新建配方 |
| ✎编辑 | 编辑选中配方（或双击行） |
| ✗删除 | 删除选中配方（有记录的配方会改为禁用而非物理删除） |

### 5.2 配方列表

| 列 | 说明 |
|---|------|
| 序号 | 组内排序 |
| 试验路径名称 | 配方的中文名称（必须唯一） |
| 系统 | 所属系统 |
| 贯穿件直径 (mm) | 贯穿件直径 |
| 试验阀门编号 | 阀门编号 |
| 泄漏率限值 | 合格判定的依据值 |
| 预充压 P2 (MPa) | 预充压压力 |
| 创建时间 | 配方创建时间 |
| 状态 | 🟢启用 / ⚪禁用 |

### 5.3 配方编辑对话框

分 3 个区域：

**① 基础信息**

| 字段 | 说明 |
|------|------|
| 试验路径名称 | 必填，不可重复 |
| 组内序号 | 排序用 |
| 所属系统 | 系统名称 |
| 启用状态 | 勾选/取消 |
| 备注说明 | 补充文字 |

**② 阀门参数**

| 字段 | 单位 |
|------|------|
| 贯穿件直径 | mm |
| 试验阀门编号 | — |
| 阀门公称直径 | mm |

**③ 试验参数**

| 字段 | 单位 |
|------|------|
| 泄漏率设计最大值 | Nml/min |
| 预充压压力 P2 | MPa |

### 5.4 版本管理

每次编辑保存都会自动创建新版本快照（保存在 RecipeVersions 表），可通过"版本历史"按钮查看所有修改记录。

> **重要**：试验记录中保存的是导入时的配方快照（JSON），后续修改配方不会影响历史记录的参数。

## 6. 试验记录

**操作入口**：左侧导航 → "试验记录"

管理所有历史试验记录，支持查询、曲线回放、批量操作。

### 6.1 查询条件（顶部两行）

**第 1 行**：

| 条件 | 说明 |
|------|------|
| 项目 | 下拉框（级联过滤机组） |
| 机组 | 下拉框（级联过滤） |
| 结果 | 全部 / 合格 / 不合格 / 未知 |

**第 2 行**：

| 条件 | 说明 |
|------|------|
| 日期范围 | 起止日期选择器 |
| 关键字 | 搜索记录编号、试验对象、测量装置、数据包名称 |
| "查询" | 执行查询 |
| "重置" | 清空所有筛选条件 |

### 6.2 记录列表（分页显示）

| 列 | 说明 |
|---|------|
| ☑ | 复选框（批量选择，表头可全选） |
| 序号 | 行号 |
| 记录编号 | 唯一编码（格式：`项目_机组_对象_时间戳`） |
| 项目 / 机组 | 所属项目和机组 |
| 对象编码 / 节点名称 | 试验对象信息 |
| 最终泄漏率 (Nml/min) | 试验结果值 |
| 泄漏限值 (Nml/min) | 判定依据 |
| 结果 | 🟢合格 / 🔴不合格 |
| 关联试验路径 | 配方名称（或"未关联试验路径"） |
| 测量装置 | 使用的装置编号 |
| 操作人员 | 执行试验的人员 |
| 试验时间 / 导入时间 | 时间信息 |
| 备注 | 备注内容 |

底部有分页控件（当前页/总条数/跳转）。

### 6.3 过程曲线回放（底部区域）

**选中一条记录后**，底部自动加载该记录的三张趋势曲线图：

| 图表 | 内容 |
|------|------|
| 压力 (MPa) | 压力曲线 |
| 温度 (℃) | 温度曲线 |
| 流量 (Nml/min) | 流量曲线 |

#### 时间范围控制
- 输入"从 ___s 到 ___s"（0=全部）→ 点击"确认" → 裁剪到指定时间段
- 图表交互：左键拖拽平移、滚轮缩放 Y 轴、悬停显示 Tracker

#### 右侧面板
- **通道图例**：压力/温度/流量各通道的名称、最小-最大值范围、单位
- **试验路径信息卡**：配方名称、系统、贯穿件直径、阀门编号、公称直径、泄漏率限值、预充压 P2、备注

### 6.4 编辑试验记录

**单条编辑**：双击记录行 → 弹出对话框 → 修改关联试验路径和备注 → 确定

> **注意**：修改试验路径后，系统会自动重新计算泄漏限值和合格/不合格判定。

### 6.5 批量操作

| 操作 | 步骤 |
|------|------|
| **批量修改试验路径** | 勾选多条记录 → 点击"批量修改试验路径" → 选择新配方 → 确定（所有选中记录更新，自动重算判定） |
| **批量删除** | 勾选多条记录 → 点击"批量删除" → 确认（不可恢复） |

### 6.6 数据上传（单文件导入）

**操作入口**：试验对象页面 → 试验对象管理 Tab → 选中节点 → "导入数据"，或数据上传页面

#### 上传流程
1. 点击 **"选择数据包文件"** → 选择 .json / .txt / .csv 文件
2. 系统自动解析文件，识别试验对象
3. 自动关联默认配方（如果试验对象已配置默认试验路径）
4. 填写/确认：记录编号、项目编码、机组编码、操作人员
5. 选择/更换试验路径（下拉框含"不使用试验路径"选项）
6. 点击 **"开始上传"**
7. 系统创建试验记录 + 过程数据，自动判定合格/不合格

#### 如果数据文件不含装置编号
弹出 **"选择测量装置"** 对话框，手动选择本次导入使用的装置。

### 6.7 批量上传

**操作入口**：试验记录页面 → "批量上传" 或数据上传页面

#### 流程
1. 点击 **"选择文件夹"** → 选择包含多个数据包文件的文件夹
2. 系统自动解析所有文件，尝试匹配试验对象（精确匹配/路径匹配）
3. 文件列表显示匹配状态：✅就绪（绿色）/ ⚠️待补充（黄色）
4. 手动补充未匹配项的项目/机组/试验对象
5. 点击 **"开始上传"** → 进度条显示上传进度
6. 完成后自动跳转到路径树页面

## 7. 实时监视

**操作入口**：左侧导航 → "实时监视"

实时监视是软件的核心功能，用于连接 PLC 实时采集数据并以曲线形式展示。

### 7.1 页面布局

```
┌─────────────────────────────────────────────────────────┐
│  第 1 行：项目 + 机组 + 试验对象 + 测量装置（下拉选择）   │
│  第 2 行：PLC地址 + 连接/断开 + 开始/停止监视 + 导出CSV  │
├─────────────────────────────────────────────────────────┤
│  实时变量表格（可编辑，含显示开关、颜色、地址、当前值）    │
├─────────────────────────────────────────────────────────┤
│  趋势曲线：显示时长 + 确认 + 自动跟随                    │
│  三张图表并排：压力 (MPa) | 温度 (℃) | 流量 (Nml/min)   │
└─────────────────────────────────────────────────────────┘
```

### 7.2 选择试验对象（必须先完成）

依次选择（级联过滤）：
1. **项目** → 2. **机组**（按项目过滤） → 3. **试验对象**（按机组过滤，显示编码+名称）
4. **测量装置**（仅显示启用状态的装置）

### 7.3 PLC 连接

| 按钮 | 功能 |
|------|------|
| PLC 地址输入框 | 输入 IP 地址（默认 127.0.0.1） |
| 保存地址 | 保存当前 IP 到运行时配置（重启后恢复配置文件中的地址） |
| 连接 PLC | 连接 PLC（自动识别 Modbus TCP 或西门子 S7 协议） |
| 断开 PLC | 断开连接（如在监视中会先停止监视） |

#### 连接状态指示
- 🔴 红色文字 = 未连接
- 🟢 绿色文字 = 已连接

#### 连接失败处理
- 状态栏显示具体错误信息
- 若启用了仿真降级（`AllowSimulationFallback=true`），自动切换为模拟数据
- 模拟数据规律：前 10 秒流量低位（~25），10 秒后陡增至 ~18000，20 秒后回落

### 7.4 开始/停止监视

#### 开始监视
1. 确保 PLC 已连接
2. 确保已选择项目、机组、试验对象、测量装置（缺一不可，否则弹出提示）
3. 点击 **"开始监视"**
4. 系统自动：
   - 创建试验记录（状态=待判定）
   - 创建过程数据占位
   - 启动定时采集（默认 1000ms 间隔）
   - 实时显示数值和曲线

#### 停止监视
点击 **"停止监视"**，系统自动：
- 保存全部已采集数据到数据库
- 计算最终泄漏率 = max(M1 最大值, M2 最大值)
- 根据泄漏限值自动判定合格/不合格
- 更新试验记录

> **数据安全**：即使不点停止，系统也会周期自动保存（约每 10 秒，随数据量增大间隔拉长到 30s → 60s → 5min），防止意外关闭丢失数据。

### 7.5 实时变量表格

工具栏：**添加变量** | **删除** | **保存配置**

| 列 | 可编辑 | 说明 |
|---|:---:|------|
| 显示 | ✅ | 复选框，控制该变量曲线是否显示 |
| 颜色 | — | 色块（自动分配，与曲线颜色一致） |
| 变量名称 | ✅ | 中文名称 |
| 西门子地址 | ✅ | 如 DB15.DBD0 |
| 寄存器地址 | ✅ | Modbus 地址（如 512, 804） |
| 数据类型 | ✅ | double/int/float/real/ushort/dword |
| 单位 | ✅ | MPa / ℃ / Nml/min 等 |
| 最小值 / 最大值 | ✅ | 曲线显示范围 |
| 当前值 | — | 最新采集值（只读） |
| 更新时间 | — | 最后成功读取时间（只读） |
| 状态 | — | 正常 / 待连接 / 未读取到数据（只读） |

> **提示**：修改后必须点击"保存配置"才能持久化到数据库，否则重启后丢失。

### 7.6 趋势曲线

三张图表分别显示压力、温度、流量，按变量的"曲线通道"属性自动分组：

| 图表 | 分组的变量 | 默认颜色 |
|------|----------|----------|
| 压力 (MPa) | CurveChannel 含"pressure"或"压力" | 蓝、紫 |
| 温度 (℃) | CurveChannel 含"temp"或"温度" | 橙 |
| 流量 (Nml/min) | CurveChannel 含"flow"或"流量" + 未归类 | 绿、青 |

#### 图表交互

| 操作 | 功能 |
|------|------|
| 左键拖拽 | 平移 X 轴（查看历史数据） |
| 滚轮 | 缩放 Y 轴（放大/缩小数值范围） |
| 鼠标悬停 | 显示 Tracker 浮层（各通道当前值） |

#### 自动跟随

勾选 **"自动"** 复选框：
- 视口自动跟随最新数据向右滚动
- Y 轴按**当前可见窗口**内的数据自适应范围
- 历史尖峰滑出窗口后，Y 轴自动缩小到当前数据范围

取消勾选：
- 视口停在当前位置，可自由拖拽查看历史
- 数据全量保留，不裁剪

#### 显示时长设置
1. 在"显示时长"输入框输入秒数（默认 600 秒 = 10 分钟）
2. 点击 **"确认"** 应用
3. 图表按新窗口对齐到最新数据，Y 轴自适应

> **注意**：所有已采集数据始终保留，显示时长只控制可见窗口，不删除任何数据。

### 7.7 导出 CSV

点击 **"导出 CSV"** → 选择保存路径 → 导出全量采集数据（所有通道、所有采样点、带时间戳）为 CSV 文件。

### 7.8 自动重连

监视过程中如果 **连续 3 次读取失败**，系统自动尝试重新连接 PLC：
- 重连成功 → 恢复监视，状态栏显示"自动重连成功"
- 重连失败 → 停止监视，状态栏显示错误信息

## 10. 数据库状态与高可用

### 10.1 数据库状态指示器

左侧导航栏底部实时显示：

- **主库**：🟢 在线 / ⚪ 离线
- **从库**：🟢 在线已配置 / ⚪ 未配置或离线
- 标记 **(当前)** 的是当前正在使用的库

### 10.2 主从自动切换

- 主库连接失败 → 自动切换到从库
- 从库恢复后 → 等待"切回等待时间"后自动切回主库
- 切换过程中数据不丢失

### 10.3 磁盘缓冲

当数据库连接中断时，已采集的数据自动缓存到本地磁盘。数据库恢复后，缓存数据自动回写到数据库，确保 **数据零丢失**。

### 10.4 自动备份

- 可配置自动备份间隔（小时）
- 可配置备份保留天数（超期自动清理）
- 备份状态在首页概览和系统维护区域实时显示

## 11. 附录：操作提示与注意事项

### 11.1 完整试验流程

```
1. 基础台账 → 确认项目/机组/试验对象/测量装置已登记
2. 试验路径 → 配置试验配方（泄漏率限值、压力参数等）
3. 试验对象管理 → 为叶子节点关联默认试验路径
4. 实时监视 → 选择试验对象 → 选择测量装置 → 连接 PLC → 开始监视
5. 等待试验完成 → 停止监视（数据自动保存，自动判定合格/不合格）
6. 试验记录 → 查看曲线回放 / 导出报告
7. （可选）数据分析 → 统计趋势
```

### 11.2 日常巡检流程

```
1. 打开软件 → 查看首页概览（合格率、异常数、数据库状态）
2. 实时监视 → 连接 PLC → 开始监视 → 观察曲线
3. 发现异常 → 在试验记录中查看详情/导出报告
```

### 11.3 数据导入流程

```
1. 现场测试完成 → 泄漏仪生成数据包（.json / .txt / .csv）
2. U 盘拷贝到本机
3. 数据上传 → 选择文件 → 确认信息 → 上传
   或：批量上传 → 选择文件夹 → 系统自动解析匹配 → 批量上传
4. 试验记录 → 确认导入成功，查看曲线
```

### 11.4 重要注意事项

1. **停止监视前不要关闭软件**：虽有自动保存机制，建议正常停止监视后再关闭
2. **定期检查数据库状态**：左下角状态指示器，确保主库在线
3. **变量配置修改后要点"保存配置"**：不保存则重启后丢失
4. **测量装置必须先在台账中登记并启用**：实时监视选择装置时只能选已启用的
5. **Y 轴自适应**：图表 Y 轴始终按当前可见窗口内的数据自动调整范围，历史尖峰滑出窗口后 Y 轴会自动缩小
6. **配方修改不影响历史记录**：每条试验记录保存的是导入时的配方快照
7. **删除操作不可恢复**：批量删除请谨慎，系统会弹出确认对话框
8. **有历史数据的节点可能无法删除**：系统会保护已产生试验数据的试验对象
9. **有记录的配方删除时会改为禁用**：而非物理删除，保证历史数据完整性
10. **远程数据库连接**：需确保 TCP/IP 协议启用、防火墙放行 1433 端口
