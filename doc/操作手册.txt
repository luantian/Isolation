一、系统概述
================================================================================

本软件用于智能安全壳隔离阀泄漏率试验的数据管理，主要功能包括：
  - 试验基础数据管理（项目、机组、试验对象、测量装置）
  - 试验配方管理
  - 试验数据导入与记录查看
  - 试验过程曲线回放与分析
  - 实时监视测量装置数据
  - 数据统计分析与报表导出
  - 用户权限管理与系统备份


二、系统启动与登录
================================================================================

【启动前准备】
1. 确保 SQL Server 服务已启动
2. 首次启动会弹出数据库配置对话框，输入 SQL Server 实例名（如 localhost 或 .\SQLEXPRESS）
3. 点击"测试连接"确认连接成功后再点"确定"

【登录】
1. 双击 IsolationLeakage.App.exe 启动程序
2. 输入用户名和密码（首次使用默认账号请联系管理员获取）
3. 点击"登录"按钮进入主界面
4. 登录后可在右上角看到当前用户名和角色

【注意】
- 连续登录失败会被锁定，需等待解锁
- 忘记密码请联系系统管理员


三、主界面导航
================================================================================

登录后进入主界面，左侧为导航栏，包含以下7个页面：

│  📋  配方管理     ← 试验配方维护     │

│  📈  数据分析     ← 统计与趋势分析   │
│  ️  系统设置     ← 用户/备份/配置   │
└─────────────────────────────────────┘

点击左侧导航项即可切换页面。

4.2  试验对象（基础数据管理）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能：管理试验相关的基础主数据。

本页面包含以下子页签：

【项目管理】
  - 新增/编辑/删除项目
  - 项目包含：项目编码、项目名称、描述等

【机组管理】
  - 为每个项目添加/编辑/删除机组
  - 机组包含：机组编码、机组名称、所属项目等

【试验对象管理】
  - 管理试验对象（阀门等被测设备）
  - 支持树形结构组织试验对象路径
  - 可设置对象编码、名称、规格等

【测量装置台账】
  - 管理测量装置（传感器/仪表）
  - 装置信息：装置编码、名称、型号、量程、精度等
  - 可启用/禁用装置
  - 装置与通讯地址绑定，用于实时数据采集


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4.3  配方管理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能：管理试验配方（试验参数配置）。

【新增配方】
  1. 点击"新增配方"按钮
  2. 填写配方信息：
     - 配方名称
     - 系统（所属系统）
     - 贯穿件直径（mm）
     - 试验阀门编号
     - 阀门公称直径（mm）
     - 泄漏率限值
     - 预充压P2（MPa）
     - 备注
  3. 点击"保存"

【编辑配方】
  - 在配方列表中选中一条记录
  - 点击"编辑"按钮修改参数
  - 保存后生成新版本（支持版本追溯）

【删除配方】
  - 选中配方后点击"删除"
  - 已关联试验记录的配方不可删除

【版本管理】
  - 每次修改自动生成新版本
  - 可查看历史版本
  - 可回退到指定版本


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4.4  试验记录
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能：查看、筛选试验记录，回放试验过程曲线。

【查询筛选】
  顶部查询栏支持以下条件筛选：
  - 项目：选择所属项目
  - 机组：选择所属机组
  - 结果：合格 / 不合格 / 全部
  - 时间范围：选择日期区间
  - 关键字：按记录编号、试验对象、测量装置或数据包名称搜索
  - 点击"查询"执行筛选，"重置"清除条件

【记录列表】
  - 显示所有符合条件的试验记录
  - 列包括：序号、记录编号、项目、机组、对象编码、最终泄漏率、
    泄漏限值、结果、使用配方、测量装置、操作人员、试验时间、
    导入时间、备注
  - 支持分页浏览
  - 支持多选（勾选框）

【过程曲线回放】
  选中一条记录后，底部显示该记录的过程曲线：

  1. 三个并排图表：
     - 压力 (MPa) — 显示各压力通道的变化曲线
     - 温度 (℃)  — 显示各温度通道的变化曲线
     - 流量 (L/min) — 显示各流量通道的变化曲线
     - 三个图表共享同一时间轴（X轴：时间/秒）

  2. 时间区间裁剪：
     - 在图表上方输入"从 X s 到 Y s"（Y=0 表示到末尾）
     - 点击"确认"裁剪显示区间
     - 切换记录时区间自动重置

  3. 右侧面板：
     - 通道图例：显示各通道的名称、范围、单位，可点击切换显隐
     - 配方参数：显示该记录关联的配方详情

【批量操作】
  - 批量修改配方：勾选多条记录后点击"批量修改配方"
  - 批量删除：勾选多条记录后点击"批量删除"（需有删除权限）

【备注编辑】
  - 双击某条记录的备注列可直接编辑备注内容

功能：实时采集并显示测量装置的传感器数据。

【装置选择】

【实时曲线】
  - 实时显示压力、温度、流量等通道的数据曲线
  - 曲线自动滚动跟随最新数据

  - 主窗口底部显示设备连接状态
  - 🟢 绿色 = 设备在线
  - 🔴 红色 = 设备离线
  - ⚪ 灰色 = 未连接

五、数据导入流程
================================================================================

【方式一：数据上传页面导入】
  1. 进入"数据上传"页面（如有的话，或通过试验记录页面操作）
  2. 选择数据文件（支持指定格式的数据包）
  3. 选择关联的项目、机组、试验对象
  4. 点击"导入"
  5. 系统自动解析数据并创建试验记录
  6. 导入完成后可在"试验记录"页面查看

【方式二：批量导入】
  1. 进入"批量导入"页面
  2. 选择多个数据文件
  3. 配置导入参数
  4. 批量执行导入

【导入后验证】
  - 导入完成后检查试验记录列表
  - 点击记录查看过程曲线是否正确
  - 核对泄漏率、结果等关键数据


六、权限说明
================================================================================

系统采用角色权限控制，不同角色可访问的功能不同：

【管理员】
  - 所有功能均可访问
  - 可管理用户和角色
  - 可执行数据备份/还原
  - 可删除试验记录

【操作员】
  - 可查看和管理试验数据
  - 可导入数据、编辑记录
  - 不可管理用户/角色
  - 不可删除记录（或有限制）

【观察员】
  - 仅可查看数据
  - 不可修改任何数据
  - 不可执行导入/删除操作

⚠️ 具体权限以管理员配置为准。


七、常见问题
================================================================================

Q1: 启动时提示"无法连接数据库"？
A1: 检查 SQL Server 服务是否启动。在 Windows 服务中确认
    "SQL Server (实例名)" 服务状态为"正在运行"。

Q2: 忘记登录密码怎么办？
A2: 联系系统管理员重置密码。

Q3: 实时监视显示设备离线？
A3: 检查测量装置的通讯连接（网线/串口），确认装置已上电且
    通讯参数配置正确。

Q4: 导入数据后看不到曲线？
A4: 确认数据包中包含过程曲线数据（TimeAxisJson / ChannelsJson）。
    旧格式数据可能只有部分通道数据。

Q5: 切换试验记录后时间区间没有重置？
A5: 已修复（v1.1.0）。切换记录时会自动重置回放区间。

Q6: 图表 X 轴不显示时间标签？
A6: 已修复（v1.1.0）。增大了图表底部空间以显示时间轴。

Q7: 如何导出数据？
A7: 在"数据分析"或"报表导出"页面，选择数据范围后点击导出，
    支持 Excel (.xlsx) 和 PDF 格式。

Q8: 数据库备份文件在哪里？
A8: 默认在程序安装目录下的 backup/ 文件夹中。也可在系统设置
    中查看和修改备份路径。


八、注意事项
================================================================================

1. 首次使用前必须正确配置 SQL Server 连接
2. 建议定期备份数据库（至少每周一次）
3. 删除操作不可恢复，请谨慎操作
4. 大量数据导入时请耐心等待，不要重复点击
5. 实时监视时确保测量装置通讯正常
6. 程序日志保存在 logs/ 目录，出问题时可提供给开发人员排查
7. 修改配方后会自动生成新版本，历史版本可追溯
