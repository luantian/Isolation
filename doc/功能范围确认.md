# 智能安全壳隔离阀泄漏率数据管理软件功能范围确认

## 1. 范围原则

本项目仅实现甲方技术规格书或我方既有技术方案文档中已经明确出现的功能。

后续设计、开发和验收均按以下原则控制范围：

1. 文档中明确有的功能，可以实现。
2. 文档中没有明确出现的功能，不主动扩展。
3. 与测量装置硬件、PID 控制、传感器采集、试验台架、实时控制相关的内容，不纳入本数据管理软件范围。
4. 首页可作为数据概览入口，但不做实时仪表盘或实时监控大屏。

## 2. 确认实现的功能

### 2.1 首页概览 / 主控台

来源：我方方案中“主控台：系统状态、核心指标及告警信息概览”。

实现边界：

- 展示系统状态、核心数据指标、最近同步/上传信息。
- 可展示异常或不合格概览。
- 不使用半圆仪表盘 Gauge。
- 不做实时控制或实时监控大屏。

### 2.2 试验对象 / 资产管理

来源：甲方规格书中“新建阀门及其他密封性部件采集路径分类新建功能”；我方方案中“资产建模与管理模块”“资产管理中心”。

实现内容：

- 项目管理。
- 机组管理。
- 工艺系统管理。
- 贯穿件管理。
- 阀门管理。
- 其他密封性部件管理。
- 试验对象路径树。
- 按设备位号搜索和定位。

### 2.3 试验参数维护

来源：甲方规格书中要求新建路径时可添加贯穿件泄漏率限值、阀门泄漏率限值、阀门试验压力及阀门类型。

实现内容：

- 贯穿件泄漏率限值。
- 阀门泄漏率限值。
- 试验压力。
- 阀门类型。
- 部件类型。

不扩展为复杂通用字典平台。

### 2.4 测量装置管理

来源：甲方规格书中“具有同时管理多台装置功能，可同时管理多台智能安全壳隔离阀泄漏率测量装置，可汇总多台装置的测量数据后集中管理测量数据”。

实现内容：

- 多台测量装置登记。
- 装置编号、名称、型号、序列号、通信方式等基础信息。
- 装置连接状态或最近同步时间提示。
- 按测量装置汇总上传数据。

不做实时装置监控大屏。

### 2.5 任务下载 / 任务下发

来源：甲方规格书中“上传下载功能，连接智能安全壳隔离阀泄漏率测量装置，选择下载的试验对象路径”；我方方案中“任务下发”。

实现内容：

- 选择试验对象路径。
- 生成下载任务。
- 下载任务至测量装置。
- 记录下载时间、目标装置和操作人员。

### 2.6 试验数据上传

来源：甲方规格书中“上传试验对象路径中的试验数据”；我方方案中“数据上传”。

实现内容：

- 从测量装置上传试验数据。
- 解析上传数据。
- 保存试验结果和过程数据。
- 记录上传时间、来源装置和操作人员。

### 2.7 历史数据不覆盖

来源：甲方规格书中“同一个试验对象路径每次上传的数据都能依次按照时间顺序存储于数据库，不会覆盖数据”；我方方案中“INSERT 操作，绝不覆盖历史数据”。

实现内容：

- 同一试验对象多次上传时新增历史记录。
- 按试验时间或上传时间顺序存储。
- 不用新数据覆盖既有历史试验记录。

### 2.8 试验记录 / 数据中心

来源：甲方规格书中要求按项目、机组号、系统、贯穿件编号、采集时间等存储试验采集数据；我方方案中“数据中心”“test_records”“test_data_details”。

实现内容：

- 试验记录列表。
- 试验记录详情。
- 按项目、机组、系统、贯穿件、阀门、时间、结果等条件查询。
- 试验过程数据存储。

### 2.9 过程数据查看

来源：甲方规格书中“自动判定和保存测量结果及过程数据”；我方方案中“压力/时间曲线”“流量/时间曲线”。

实现内容：

- 保存单次试验过程数据。
- 查看压力/时间曲线。
- 查看流量/时间曲线。

前提：测量装置上传数据中包含对应过程数据。

### 2.10 数据分析

来源：甲方规格书中“数据分析功能”；我方方案中“分析中心”“泄漏率历史趋势图”。

实现内容：

- 按阀门类型分类形成故障类型趋势图。
- 单个阀门试验次数统计。
- 试验对象单次合格率统计。
- 整台机组阀门合格情况统计。
- 阀门泄漏率历史趋势分析。
- 不同类型阀门泄漏率曲线分析。

### 2.11 用户权限管理

来源：甲方规格书中“多用户账号分类管理功能，依据用户需求控制不同类型用户账号的使用权限”；我方方案中“用户与权限管理模块”“RBAC”。

实现内容：

- 用户管理。
- 角色管理。
- 权限控制。
- 登录认证。

### 2.12 数据备份

来源：甲方规格书中“可定期或手动备份数据库”；我方方案中“数据备份与恢复”。

实现内容：

- 定期备份。
- 手动备份。
- 数据恢复。
- 备份/恢复操作记录。

### 2.13 数据库同步和迁移

来源：甲方规格书中“具有数据库同步和迁移功能，可迁移数据库至其他服务器或从其他服务器迁移数据至数据库”；我方方案中“数据迁移”。

实现内容：

- 数据库迁移至其他服务器。
- 从其他服务器迁移数据至当前数据库。
- 数据同步或同步辅助工具。

### 2.14 操作日志 / 审计

来源：我方方案中“操作日志审计”“系统设置包括日志审计”。

实现内容：

- 登录日志。
- 数据新增、修改、删除日志。
- 任务下载日志。
- 数据上传日志。
- 导出日志。
- 备份、恢复、迁移日志。

### 2.15 报告导出

来源：甲方文件清单中“数据分析-管理软件设计方案报告”“管理软件使用说明书”；我方方案中“导出报告”。

实现内容：

- 试验记录导出。
- 数据分析结果导出。
- 基础报告导出。

不扩展为复杂报表平台。

### 2.16 状态栏 / 连接状态提示

来源：我方方案中“底部状态栏显示最近一次与现场测量装置的数据同步时间、设备连接状态在线/离线”。

实现内容：

- 显示数据库连接状态。
- 显示当前用户。
- 显示最近同步时间。
- 显示测量装置在线/离线状态。

## 3. 确认不实现的功能

以下功能不在当前数据管理软件范围内：

1. 半圆仪表盘 Gauge。
2. 实时控制界面。
3. PID 控制界面。
4. 传感器实时采集界面。
5. 实时监控大屏。
6. 实时报警管理闭环。
7. 电子签名。
8. 审批流。
9. AI 分析。
10. 预测性维护。
11. 复杂通用字典平台。
12. 测量装置硬件设计。
13. 试验台架操作。
14. 传感器校准。
15. 泄漏率机理研究。

## 4. 页面范围

后续软件页面按以下范围设计：

1. 首页概览。
2. 试验对象管理。
3. 测量装置管理。
4. 任务下载。
5. 数据上传。
6. 试验记录。
7. 数据分析。
8. 报告导出。
9. 系统设置。

系统设置中包含：

1. 用户权限。
2. 数据备份。
3. 数据库同步/迁移。
4. 操作日志。

## 5. UI 设计边界

界面风格参考工业控制/工程管理软件：

- 蓝色模块标题条。
- 白色内容面板。
- 浅灰工作区背景。
- 细边框分区。
- 高信息密度。
- 大数字指标。
- 状态点。
- 表格和树形结构。

不采用实时仪表盘作为主视觉，不做花哨 App 风格。
