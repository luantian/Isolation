================================================================================
实时读取演示设置说明 — Modbus TCP 仿真演示
================================================================================
用途：在没有真实测量装置（西门子 1211C PLC）的情况下，用 Modbus TCP 仿真软件
      在演示机上模拟装置，让数据管理软件【真实地通过网络 TCP 读取】5 通道数据，
      演示"实时读取数据"功能。数据由仿真软件提供，链路真实，不依赖现场硬件。
准备日期：2026-06-28


================================================================================
一、原理说明（演示时可对甲方讲）
================================================================================

- 软件作为 Modbus TCP 主站（Master），主动连接 PLC（从站 Slave）读取保持寄存器。
- 真实现场：连西门子 1211C PLC（IP 192.168.1.12，端口 502）。
- 演示环境：在演示机本机跑一个 Modbus TCP 从站仿真器，软件连 127.0.0.1:502
  （或仿真器所在机器 IP），真实走 Modbus 协议读数。
- 软件每 100ms（可配）批量读取 5 个寄存器，实时刷新变量表和 5 通道趋势曲线。

⚠️ 这是【真实的网络读取链路】，不是软件内部造假数据。可以如实对甲方说
   "软件通过 Modbus TCP 读取装置寄存器，现在连的是仿真从站"。


================================================================================
二、5 个通道的寄存器地址（务必和仿真器对齐）
================================================================================

软件按 plc-registers.json 配置读取，当前配置如下：

  通道          变量名      寄存器地址   数据类型   单位     曲线
  -----------   ---------   ----------   --------   ------   --------
  压力 P1       实时压力P1   512          double*    MPa      压力(蓝)
  流量 M1       瞬时流量M1   804          ushort     L/min    流量M1(绿)
  流量 M2       瞬时流量M2   806          ushort     L/min    流量M2(青)
  温度 T        温度T        500          double*    ℃       温度(橙)
  压力 P2       压力P2       504          double*    MPa      压力P2(紫)

  * double 实际按 32 位 IEEE754 单精度浮点读取（占 2 个连续保持寄存器）。
    ushort 占 1 个保持寄存器（16 位无符号整数）。

注意：这些是【保持寄存器(Holding Register)地址】。软件用功能码 03
      （Read Holding Registers）读取。仿真器里要把数据放在保持寄存器区，
      地址对应上表。


================================================================================
三、字节序（最容易踩的坑，务必匹配）
================================================================================

软件读 double（float）时的字节组装方式（见 ModbusPlcConnection.ReadDoubleAsync）：
- 读 2 个连续寄存器 reg[0]、reg[1]
- 字节顺序：reg[0] 低字节、reg[0] 高字节、reg[1] 低字节、reg[1] 高字节
- 即 "低位寄存器在前 (Little-Endian word order) + 每寄存器小端字节"

在仿真器里设置 float 值时，要选择匹配的字节序，否则浮点数显示会乱（变成很大/很小的乱数）。
- 如果仿真器显示的浮点数和你设的不一样，就切换字节序选项
  （常见叫法：Word Order / Byte Order，试 "Little-Endian" 或 "Swap" 几种组合）。
- ushort（M1/M2）是单寄存器整数，一般不受字节序影响，直接设整数即可。

💡 演示前一定要先试一遍，确认 5 个值显示正常，再正式演。


================================================================================
四、推荐仿真器（任选其一，都是免费/常用）
================================================================================

1. Modbus Slave（Witte Software，最常用，收费但有试用）
   - 新建一个 Slave 定义，功能码选 03 Holding Registers
   - 设置起始地址覆盖 500~807 区间
   - Connection → Modbus TCP/IP，端口 502
   - Display → 选 Float，调字节序匹配（见第三节）

2. pyModSlave / QModMaster（开源免费）

3. ModRSsim2（开源免费，老牌 PLC 仿真器）

4. 自己写一个 Python 从站（最可控，推荐，见第六节脚本）


================================================================================
五、演示操作步骤
================================================================================

【演示前准备】
1. 在演示机启动 Modbus TCP 从站仿真器，监听端口 502。
2. 在仿真器里设置 5 个寄存器的值：
   - 地址 512（float）= 例如 1.5    （压力 P1）
   - 地址 804（ushort）= 例如 20    （流量 M1）
   - 地址 806（ushort）= 例如 18    （流量 M2）
   - 地址 500（float）= 例如 25.0   （温度 T）
   - 地址 504（float）= 例如 1.2    （压力 P2）
3. 确认字节序匹配，float 值显示正常。
4. 让这些值能【动起来】更好看（仿真器的自动递增/正弦功能，或第六节脚本会自动变化）。

【现场演示】
1. 打开软件 → 进入"实时监控"页面。
2. PLC 地址填：127.0.0.1（仿真器在本机）或仿真器所在机器 IP。
3. 点"连接 PLC" → 状态显示"已连接 PLC tcp://127.0.0.1:502"。
   ⚠️ 如果显示"[模拟] 已连接（仿真数据演示模式）"，说明没连上仿真器、
      降级成了软件内置模拟。检查：仿真器是否在跑、端口对不对、防火墙。
4. 点"开始监视" → 变量表 5 个变量实时刷新当前值，下方趋势曲线 5 条线实时滚动。
5. 让甲方看：5 通道（压力P1/流量M1/流量M2/温度T/压力P2）实时曲线 + 数值表。
6. 可点"导出CSV" → 导出的就是和装置导出格式一致的 5 通道 CSV，
   说明"现场采集的数据可以直接导出、也可以走批量导入入库"，把实时和导入串起来。
7. 点"停止监视"结束。

【演示话术】
"软件作为 Modbus TCP 主站，实时读取测量装置 PLC 的 5 个通道——压力P1、
流量M1、流量M2、温度、压力P2，刷新周期 100 毫秒，实时绘制趋势曲线。现在连的是
仿真从站，现场换成真实装置 IP 即可。采集的数据可一键导出为标准 CSV，
再通过批量导入归档入库。"


================================================================================
六、（可选）Python 自动变化从站脚本
================================================================================
最可控、最稳。装 pymodbus 后运行，自动让 5 个值平滑变化，曲线好看。

  pip install pymodbus

  --- save as modbus_sim.py, run: python modbus_sim.py ---
  import asyncio, math, struct, time
  from pymodbus.server import StartAsyncTcpServer
  from pymodbus.datastore import ModbusSlaveContext, ModbusServerContext
  from pymodbus.datastore import ModbusSequentialDataBlock

  # 保持寄存器区，地址 0~1000
  store = ModbusSlaveContext(hr=ModbusSequentialDataBlock(0, [0]*1001))
  context = ModbusServerContext(slaves=store, single=True)

  def set_float(addr, value):
      # 与软件字节序匹配：低位寄存器在前，每寄存器小端
      b = struct.pack('<f', value)              # 小端 float -> 4 bytes
      reg0 = b[0] | (b[1] << 8)
      reg1 = b[2] | (b[3] << 8)
      store.setValues(3, addr, [reg0, reg1])     # 功能码3=保持寄存器

  def set_ushort(addr, value):
      store.setValues(3, addr, [int(value) & 0xFFFF])

  async def updater():
      t = 0
      while True:
          set_float(512, 1.5 + 0.3*math.sin(t/10))      # 压力P1
          set_ushort(804, int(20 + 5*math.sin(t/7)))     # 流量M1
          set_ushort(806, int(18 + 4*math.cos(t/8)))     # 流量M2
          set_float(500, 25.0 + 2*math.sin(t/15))        # 温度T
          set_float(504, 1.2 + 0.2*math.cos(t/9))        # 压力P2
          t += 1
          await asyncio.sleep(0.1)

  async def main():
      asyncio.create_task(updater())
      print("Modbus TCP 从站已启动，监听 0.0.0.0:502")
      await StartAsyncTcpServer(context, address=("0.0.0.0", 502))

  asyncio.run(main())
  --- end ---

注意：
- 端口 502 在 Windows 上可能需要管理员权限运行；若被占用可改用 5020，
  同时把软件 PLC 地址端口也改一致（plc-registers.json 里 Port 字段，
  或界面上目前固定 502——若要改端口需在配置文件改）。
- 如果浮点数显示乱，把 struct.pack('<f', value) 的 '<' 改成 '>' 试试
  （大端），与软件字节序对齐。


================================================================================
七、故障排查
================================================================================

现象：点"连接PLC"后显示"[模拟]已连接（仿真数据演示模式）"
原因：没连上仿真器，软件降级用了内置模拟数据
排查：① 仿真器是否在运行、监听 502；② IP/端口对不对；③ 防火墙是否拦截 502；
      ④ 本机连本机用 127.0.0.1

现象：连上了但浮点数（压力/温度）是乱数（极大/极小）
原因：字节序不匹配
排查：在仿真器或脚本里切换 float 字节序（见第三节、第六节注意）

现象：流量 M1/M2 整数正常，但压力/温度乱
原因：同上，float 字节序问题（整数不受影响，浮点才受）

现象：曲线不动/没数据
排查：① 是否点了"开始监视"；② 变量表"当前值"列有没有刷新；
      ② 仿真器的值是不是固定不变的（固定值曲线是直线，正常；想好看用脚本让它动）
