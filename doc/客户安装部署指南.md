# 智能安全壳隔离阀泄漏率数据管理软件 — 安装部署指南

**版本：** v2026.08  
**发布日期：** 2026 年 8 月

---

## 1. 系统要求

- **操作系统：** Windows 10/11（64 位）
- **数据库：** SQL Server 2019 Express 或更高版本
- **.NET 运行时：** 已包含在发布包中，无需单独安装

---

## 2. 安装 SQL Server Express

从微软官网下载 SQL Server Express：
https://www.microsoft.com/zh-cn/sql-server/sql-server-downloads

### 2.1 安装 SQL Server

1. 双击下载的 `SQLServer*-Express.exe`，选择"基本"安装类型
2. 接受许可条款，点击"下一步"
3. **选择实例**：保持默认的**命名实例** `SQLEXPRESS`，不要修改
4. **安装路径**：保持默认即可，点击"下一步"开始安装
5. 等待安装完成，点击"关闭"

建议同时安装 SQL Server Management Studio (SSMS)：
https://docs.microsoft.com/zh-cn/sql/ssms/download-sql-server-management-studio-ssms

### 2.2 配置数据库

安装完成后需要启用 sa 账户并配置网络访问，按以下步骤操作：

**第一步：设置 sa 账户**

1. 打开 SSMS，在"连接到服务器"对话框中：
   - **服务器名称：** `localhost\SQLEXPRESS`（或 `.\SQLEXPRESS`）
   - **身份验证：** Windows 身份验证
   - 点击"连接"

2. 在左侧"对象资源管理器"中，展开"安全性" → "登录名"

3. 双击 `sa`，在弹出窗口中：
   - 选择"常规"页 → 设置新密码（请记住此密码）
   - 选择"状态"页 → 将"登录"设置为 **启用**
   - 点击"确定"

**第二步：启用混合模式和网络访问**

4. 右键点击服务器名称（最顶部节点）→ "属性" → "安全性"
   - 将"服务器身份验证"改为 **SQL Server 和 Windows 身份验证模式**
   - 点击"确定"

5. 打开 **SQL Server Configuration Manager**（开始菜单搜索即可）

6. 展开"SQL Server 网络配置" → 点击"SQLEXPRESS 的协议"
   - 右键"TCP/IP" → "启用"

**第三步：重启服务**

7. 按 `Win + R`，输入 `services.msc`
8. 找到 `SQL Server (SQLEXPRESS)`，右键 → "重新启动"

### 2.3 验证 sa 账户登录

1. 在 SSMS 中"断开连接"
2. 重新"连接"，在对话框中：
   - **服务器名称：** `localhost\SQLEXPRESS`
   - **身份验证：** SQL Server 身份验证
   - **登录名：** `sa`
   - **密码：** 刚才设置的密码
3. 点击"连接"，验证是否成功

## 3. 安装管理软件

将 `IsolationLeakageApp_v20260803_win-x64_SelfContained.zip` 解压到目标目录（如 `C:\IsolationLeakage\`）。

主程序：`IsolationLeakage.App.exe`

---

## 4. 配置数据库连接

编辑软件目录下的 `appsettings.json`，修改 `DefaultConnection`：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost\\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=YourPassword;Connect Timeout=10;Trust Server Certificate=True;",
    "SecondaryConnection": ""
  }
}
```

**参数说明：**
- `Server`：数据库服务器地址（单机用 `localhost`，远程用 IP）
- `Database`：固定为 `IsolationLeakageDb`
- `User Id` / `Password`：数据库账户密码

> **注意：** 无需手动创建数据库。软件首次启动时会自动创建 `IsolationLeakageDb` 并初始化表结构。

双击 `IsolationLeakage.App.exe` 启动软件。

**默认账户：**
- 管理员：`admin` / `admin123`
- 操作员：`operator` / `operator123`

**验证步骤：**
1. 查看左下角数据库状态（● 绿色表示正常）
2. 尝试登录系统
3. 进入"系统设置"确认连接正常

## 6. 常见问题

**Q: 提示"数据库连接失败"？**
- 检查 SQL Server 服务是否启动（`services.msc` → `SQL Server (SQLEXPRESS)`）
- 核对 `appsettings.json` 中的服务器地址、用户名、密码
- 远程部署时检查防火墙是否开放 1433 端口

**Q: 提示"数据库迁移失败"？**
- 确保 `sa` 用户具有 `db_owner` 角色
- 检查数据库文件目录是否有写入权限

**Q: 日志文件在哪里？**
- 位于软件目录下的 `logs\` 文件夹
- 遇到问题可将日志发给技术支持
