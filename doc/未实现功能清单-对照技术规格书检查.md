## 📝 备注与建议

1. **关于泄漏率计算**：当前代码注释明确说明"装置已算好最终泄漏率与合格判定，软件只读取、不计算"。建议与甲方确认是否需要软件端具备计算能力。

2. **关于温压补偿**：如果计算完全在硬件端完成，软件端至少需要实现"补偿参数配置"和"补偿后数据验证"功能。

3. **关于DCS对接**：建议先确认甲方DCS系统品牌和接口规范，避免盲开发。

4. **关于长周期存储**：SQL Server Express有10GB限制，5年数据量可能超出，需提前规划：
   - 方案A：升级到SQL Server标准版
   - 方案B：实现历史数据归档到文件系统
   - 方案C：定期导出冷数据
