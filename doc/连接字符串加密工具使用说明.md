# 连接字符串加密工具

## 使用方法

### 方法 1：使用 PowerShell 脚本（推荐）

```powershell
# 加密连接字符串
.\tools\Encrypt-ConnectionString.ps1 "Server=192.168.1.100\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=Admin@123;"
```

### 方法 2：在代码中调用

```csharp
using IsolationLeakage.App.Security;

string encrypted = ConnectionStringEncryptor.Encrypt("Server=...;Password=...;");
string decrypted = ConnectionStringEncryptor.Decrypt(encrypted);
```

## 配置示例

### 加密前（明文）

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=192.168.1.100\\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=Admin@123;"
  }
}
```

### 加密后

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "ENC:AQAAANCMnd8BFmERjAoAwB..."
  }
}
```

## 工作原理

1. **加密**：使用 Windows DPAPI（数据保护 API）加密
2. **存储**：加密后的字符串以 `ENC:` 前缀标识
3. **解密**：程序启动时自动检测并解密
4. **安全**：加密后的数据只能在本机解密

## 注意事项

⚠️ **加密后的连接字符串只能在本机解密！**

- 不要在 A 机器加密后复制到 B 机器使用
- 如果需要在多台机器部署，每台机器都需要单独加密
- 备份配置文件时，加密的字符串无法在其他机器恢复

## 部署流程

1. 在目标机器上运行加密脚本
2. 将加密后的字符串复制到 `appsettings.json`
3. 启动程序，程序会自动解密

## PowerShell 脚本

创建 `tools/Encrypt-ConnectionString.ps1`：

```powershell
param(
    [Parameter(Mandatory=$true)]
    [string]$ConnectionString
)

Add-Type -AssemblyName System.Security

try {
    $plainBytes = [System.Text.Encoding]::UTF8.GetBytes($ConnectionString)
    $encryptedBytes = [System.Security.Cryptography.ProtectedData]::Protect(
        $plainBytes,
        $null,
        [System.Security.Cryptography.DataProtectionScope]::LocalMachine
    )
    $base64 = [Convert]::ToBase64String($encryptedBytes)
    $encrypted = "ENC:$base64"

    Write-Host ""
    Write-Host "✅ 加密成功！" -ForegroundColor Green
    Write-Host ""
    Write-Host "明文长度：$($ConnectionString.Length) 字符"
    Write-Host "加密长度：$($encrypted.Length) 字符"
    Write-Host ""
    Write-Host "加密后的连接字符串："
    Write-Host $encrypted
    Write-Host ""
    Write-Host "请将上面的字符串复制到 appsettings.json 中："
    Write-Host ""
    Write-Host "{"
    Write-Host "  `"ConnectionStrings`": {"
    Write-Host "    `"DefaultConnection`": `"$encrypted`""
    Write-Host "  }"
    Write-Host "}"
}
catch {
    Write-Host "❌ 加密失败：$($_.Exception.Message)" -ForegroundColor Red
    Write-Host ""
    Write-Host "可能的原因："
    Write-Host "  1. 不在 Windows 环境下运行"
    Write-Host "  2. 没有 DataProtection API 权限"
    Write-Host "  3. 连接字符串格式错误"
    exit 1
}
```
