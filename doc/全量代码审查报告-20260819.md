## 二、中危缺陷（按主题聚类，约 63 项）

### 主题1：长生命周期共享 DbContext（6 个代理独立命中，#11 持续残留）
- TestRecordService 挂共享单例，并发上传/批量导入抛 "second operation" 异常
- MonitorVariableConfigService 同样共享单例；**failover 后 VM 缓存旧服务实例 → ObjectDisposedException**（4 个代理独立发现：实时监视保存配置/配方页/上传页/监控配置）
- ValidateAndUploadAsync 校验阶段仍用 AppServices.DbContext；CheckDuplicateAsync 无 AsNoTracking，大批量导入 ChangeTracker 无限膨胀二次方变慢
- ProjectUnitManagementViewModel.cs:715 批量导入 ChangeTracker.Clear() 清空全局跟踪器

### 主题2：fire-and-forget / async void / 竞态（#4 复发族）
- 添加变量/保存配置 async void 无重入保护 + VariableName 无唯一索引 → 双击重复行
- 统计页级联下拉、实时监视项目/机组联动、用户管理搜索均无代际守卫
- TaskDownload 创建任务无防抖无权限；批量解析中可再次触发解析交错
- 编译警告 CS4014×3（RealtimeMonitorViewModel.cs:2327/2462/2476 未 await）

### 主题3：静默失败/反馈缺失
- 项目机组页 Message 无处显示（J1 根因）；统计分析页 StatusMessage 只绑在 Tab3，其它 4 个 Tab 下所有提示不可见
- 多行 CSV 行级失败不写 ErrorMessage、进度恒 0%、误报"全部成功"
- 导入事务回滚后 Created/Updated 计数不重置，弹窗误导
- 回放区间无效只写日志无 UI 反馈

### 主题4：数据口径/业务正确性
- **泄漏率单位疑点**：规格书 0.1~1000 L/h vs 校验注释 0.1~1000 Nml/min，相差 16.7 倍，必有一错（需与甲方确认）
- "不合格数"= total-pass 把未判定(Unknown)计入不合格；三处统计口径互不一致
- 曲线↔汇总按毫秒时间戳配对必然失配 → 同一试验生成两条记录（曲线挂错记录）
- RecordCode 无 50 字符截断（按文档导入路径已实现，批量/单文件漏掉）→ 长位号入库失败
- 改配到限值为 0 的路径时快照与字段自相矛盾；阀门判定两 Tab 口径不一致（NodeType vs ObjectType）
- 压力单位换算链：SaveConfig 丢 unit 参数致压力轴刻度放大 1000 倍；MPa→kPa 保存后量程缩小 1000 倍

### 主题5：故障切换配套缺陷
- 操作日志查询固定打主库，从库期间页面不可用
- ReloadConfiguration 与健康检查竞态（旧快照驱动新配置切换）；ForceSwitchTo 仍在锁内 RaiseDbConnectionChanged（#16 残留变体）
- 正常退出不 Flush 缓冲不落盘，主库断开期间关机数据无报告静默消失；RecoverFromDisk 不清理 buffer_*.json 每次启动重复告警
- 备份间隔 ≥597 小时 DispatcherTimer 抛异常自动备份静默停摆；保留天数 0/负数清空全部日志

### 主题6：UI/交互缺陷
- 编辑装置"有效期"既不回显也不落库；编辑节点对话框标题恒"新建"、改编号不生效却提示成功
- 切基础数据页任意 tab 强制重置用户选择；重置按钮不恢复机组/系统下拉全量
- 空结果残留旧图表；删除变量改名后漏删重启"复活"；编辑对话框校验后置输入全丢
- 批量导入 finally 中 FlushAsync 抛异常永久卡死导入状态
- 大曲线 JSON/批量解析/ClosedXML 导出多处仍在 UI 线程同步执行（#6 残留）
- 台账删除装置与监视页下拉无联动 → 撞 FK 原始异常；装置选择器不过滤停用/过期装置
- "空"占位值当合法编号建库（真实建出名为"空"的阀门/系统）

### 主题7：安全
- App.xaml.cs:188 完整连接串含 sa 密码明文写日志（每次启动，保留 30 天）——已人工复核属实
- admin 强制解锁+清零失败计数在正式启动路径，重启绕过暴力破解锁定
- 无"最后一个管理员"保护，可停用自己/去掉自己的 admin 角色
- 数据库配置/主从切换按钮无 PermissionGuard 无审计日志；统计导出、配方导出 CSV 缺权限守卫
- 开始/停止监视、连接/断开 PLC、导出 CSV 无权限守卫（只读角色可开试验，需确认是否符合权限模型）
- 用户管理密码框用明文 TextBox；sa 明文密码仍在 appsettings.json（已知未修）
