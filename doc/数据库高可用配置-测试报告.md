## 代码审查发现的问题

### 问题 1: 多余的 null 检查 ✅ 已修复
**位置:** `SecAuthMode_Changed` 方法  
**原代码:**
```csharp
if (SecSqlAuthPanel != null)
{
    SecSqlAuthPanel.Visibility = ...
}
```

**修复:**
```csharp
SecSqlAuthPanel.Visibility = SecSqlAuthRadio.IsChecked == true
    ? Visibility.Visible
    : Visibility.Collapsed;
```

**原因:** `SecSqlAuthPanel` 是 XAML 定义的控件，事件触发时肯定存在，null 检查多余。

---

### 问题 2: 缺少输入验证 ✅ 已修复
**位置:** `TestSecondary_Click` 方法  
**原代码:**
```csharp
var server = SecondaryServerTextBox.Text.Trim();
if (string.IsNullOrEmpty(server)) return;
```

**修复:**
```csharp
var server = SecondaryServerTextBox.Text.Trim();
if (string.IsNullOrEmpty(server))
{
    MessageBox.Show("请输入从库服务器地址。", "提示", ...);
    return;
}

// 如果选择 SQL Server 身份验证，验证用户名和密码
if (SecSqlAuthRadio.IsChecked == true)
{
    var username = SecSqlUsernameTextBox.Text.Trim();
    var password = SecSqlPasswordBox.Password;

    if (string.IsNullOrEmpty(username))
    {
        MessageBox.Show("请输入 SQL Server 用户名。", "提示", ...);
        SecSqlUsernameTextBox.Focus();
        return;
    }

    if (string.IsNullOrEmpty(password))
    {
        MessageBox.Show("请输入 SQL Server 密码。", "提示", ...);
        SecSqlPasswordBox.Focus();
        return;
    }
}
```

**原因:** 空值验证提供友好的用户提示，而不是等待连接失败后才显示错误。

---

### 问题 3: 重复设置面板可见性 ⚠️ 保留现状
**位置:** `LoadCurrentConfig` 方法（第 46-47 行）  
**现象:**
- 第 46 行：`SecSqlAuthRadio.IsChecked = true` 触发 `SecAuthMode_Changed`
- 第 47 行：显式设置 `SecSqlAuthPanel.Visibility = Visible`
- `SecAuthMode_Changed` 也会设置一次

**决定:** 保留现状  
**原因:** 
- 不影响功能
- 显式设置提高代码可读性
- 移除可能导致理解困难
