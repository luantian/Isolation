# 试验对象路径管理业务设计

## 1. 页面定位

页面名称定为“试验对象路径管理”。

本页面只负责在项目、机组范围内维护试验对象采集路径及其参数。

本页面不负责任务下载、数据上传、完整试验记录查询、数据分析、报告导出、测量装置管理、用户权限、备份迁移和操作日志。

## 2. 页面布局

页面采用以下布局：

```text
顶部：项目选择、机组选择、搜索框
左侧：试验对象路径树
右侧上：当前节点详情
右侧下：当前路径数据概览
```

## 3. 路径节点类型

左侧树只允许以下节点类型：

1. 工艺系统。
2. 贯穿件。
3. 阀门。
4. 其他密封性部件。

不开放任意自定义节点，不开放多级自定义分组。

## 4. 允许的层级

允许以下路径层级：

```text
系统 -> 贯穿件 -> 阀门
系统 -> 贯穿件 -> 其他密封性部件
系统 -> 阀门
系统 -> 其他密封性部件
贯穿件 -> 阀门
贯穿件 -> 其他密封性部件
其他密封性部件
```

不默认开放“阀门直接挂在机组下”。

## 5. 字段设计

系统节点字段：

```text
系统编号
系统名称
备注
```

贯穿件节点字段：

```text
贯穿件编号
贯穿件名称
贯穿件泄漏率限值
备注
```

阀门节点字段：

```text
阀门编号
阀门名称
阀门类型
阀门泄漏率限值
阀门试验压力
备注
```

其他密封性部件节点字段：

```text
部件编号
部件名称
部件类型
部件泄漏率限值
试验压力
备注
```

## 6. 操作设计

页面允许以下操作：

1. 新建系统。
2. 新建贯穿件。
3. 新建阀门。
4. 新建其他部件。
5. 修改。
6. 删除。
7. 搜索定位。

删除保护：

```text
已有历史数据的节点不允许直接删除。
```

## 7. 当前路径数据概览

右侧下方只展示轻量数据概览：

1. 最近试验时间。
2. 最近泄漏率。
3. 最近判定结果。
4. 累计试验次数。
5. 不合格次数。
6. 最近上传装置。

不做完整试验记录查询，不做趋势分析。

## 8. 实现说明

当前实现先使用内存示例数据，便于验证页面结构、交互和字段布局。

后续接数据库时，仍保持本页面业务边界不变。
