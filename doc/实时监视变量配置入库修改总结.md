## 下一步操作

### 1. 生成数据库迁移

打开包管理器控制台（或命令行），在项目根目录执行：

```bash
cd F:\workspace\cechuang\projects\Isolation
dotnet ef migrations add AddMonitorVariableConfig --project src/IsolationLeakage.App
```

### 2. 更新数据库

```bash
dotnet ef database update --project src/IsolationLeakage.App
```

### 3. 验证

1. 启动应用程序
2. 进入实时监视页面
3. 首次运行时会自动插入 5 个默认变量：
   - 试验压力 (MPa)
   - 泄漏压力 (MPa)
   - 大气压力 (MPa)
   - 温度 (℃)
   - 流量 (L/min)
4. 这些变量现在存储在数据库的 `MonitorVariableConfig` 表中

## 后续可扩展功能

可以添加一个管理界面，让用户：
- 添加新变量

在"系统设置"页面添加一个"实时监视变量配置"按钮，点击后打开变量管理对话框。
