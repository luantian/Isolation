# 数据库连接字符串加密部署指南

## 概述

本指南介绍如何在甲方现场部署时加密数据库连接字符串，确保密码安全存储。

---

## 加密原理

使用 **Windows DPAPI（数据保护 API）** 加密连接字符串：

- ✅ Windows 内置，无需额外依赖
- ✅ 使用机器密钥加密，只有本机可以解密
- ✅ 加密强度高，符合安全要求
- ⚠️ 加密后的字符串不能跨机器使用

---

## 部署流程

### 第 1 步：准备连接字符串

在甲方现场，准备主库和从库的连接字符串：

```
主库：Server=192.168.1.100\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=甲方密码;
从库：Server=192.168.1.101\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=甲方密码;
```

### 第 2 步：在主库服务器上加密

1. 登录到**主库服务器**（192.168.1.100）

2. 打开 PowerShell（管理员身份）

3. 进入工具目录：
   ```powershell
   cd C:\IsolationLeakage\tools
   ```

4. 运行加密脚本：
   ```powershell
   .\Encrypt-ConnectionString.ps1 "Server=192.168.1.100\SQLEXPRESS;Database=IsolationLeakageDb;User Id=sa;Password=甲方密码;"
   ```

5. 复制输出的加密字符串（以 `ENC:` 开头）

### 第 3 步：在从库服务器上加密

1. 登录到**从库服务器**（192.168.1.101）

2. 重复第 2 步的操作，加密从库连接字符串

### 第 4 步：修改配置文件

1. 打开 `appsettings.json`

2. 将加密后的字符串填入配置：
   ```json
   {
     "ConnectionStrings": {
       "DefaultConnection": "ENC:AQAAANCMnd8BFmERjAoAwB...（主库加密字符串）",
       "SecondaryConnection": "ENC:AQAAANCMnd8BFmERjAoAwB...（从库加密字符串）"
     },
     "Failover": {
       "Enabled": true,
       "HealthCheckIntervalSeconds": 15,
       "ConnectionTimeoutSeconds": 5,
       "FailbackDelaySeconds": 60,
       "MaxRetryBeforeFailover": 2
     }
   }
   ```

3. 保存文件

### 第 5 步：验证解密

1. 在每台服务器上运行解密验证脚本：
   ```powershell
   .\Decrypt-ConnectionString.ps1 "ENC:AQAAANCMnd8BFmERjAoAwB..."
   ```

2. 确认解密后的连接字符串正确

3. 确认服务器、数据库、用户名、密码都正确

### 第 6 步：启动程序

1. 启动应用程序

2. 程序会自动检测加密的连接字符串并解密

3. 观察日志，确认连接成功

## 常见问题

### Q1: 加密后的字符串可以复制到其他机器使用吗？

**不可以！** 加密后的字符串只能在本机解密。

如果需要在多台机器部署，每台机器都需要单独加密。

### Q2: 重装系统后，加密的字符串还能用吗？

**不能！** 重装系统后机器密钥会改变，加密的字符串无法解密。

重装系统后需要重新加密。

### Q3: 如何判断连接字符串是否已加密？

加密的连接字符串以 `ENC:` 开头。

程序会自动检测，如果已加密则解密，如果未加密则直接使用。

### Q4: 加密失败怎么办？

可能的原因：
1. 不在 Windows 环境下运行
2. 没有 DataProtection API 权限
3. 连接字符串格式错误

解决方法：
- 确保在 Windows 环境下运行
- 使用管理员身份运行 PowerShell
- 检查连接字符串格式是否正确

## 安全建议

### 1. 不要使用 sa 账号

建议创建专用的应用程序账号，只授予必要的权限：

```sql
CREATE LOGIN appuser WITH PASSWORD = '强密码';
CREATE USER appuser FOR LOGIN appuser;
ALTER ROLE db_datareader ADD MEMBER appuser;
ALTER ROLE db_datawriter ADD MEMBER appuser;
```

### 2. 使用强密码

密码长度至少 12 位，包含：
- 大写字母
- 小写字母
- 数字
- 特殊字符

### 3. 定期更换密码

建议每 90 天更换一次数据库密码。

### 4. 限制网络访问

使用防火墙限制数据库端口的访问：
- 只允许应用服务器访问数据库端口
- 禁止外部网络直接访问数据库

### 5. 启用 SQL Server 审计

记录所有数据库访问日志，便于安全审计。

## 检查清单

部署前确认以下事项：

- [ ] 主库和从库的 SQL Server 服务已启动
- [ ] 主库和从库的数据已同步
- [ ] 主库和从库的网络连通性正常
- [ ] 防火墙已开放数据库端口（1433）
- [ ] 已在主库服务器上加密主库连接字符串
- [ ] 已在从库服务器上加密从库连接字符串
- [ ] 已将加密后的字符串复制到 appsettings.json
- [ ] 已验证解密后的连接字符串正确
- [ ] 已启动程序并确认连接成功
